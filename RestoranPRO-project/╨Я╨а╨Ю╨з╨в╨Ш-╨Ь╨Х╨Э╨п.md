# РесторанПРО — сборка программы для Windows и Android

Из этого проекта получаются:
- **РесторанПРО Setup.exe** — для компьютера и моноблока (Windows)
- **app-debug.apk** — для Android-телефонов и планшетов
- iPhone / iPad — через Safari: «Поделиться» → «На экран Домой» (нужна ссылка на PWA-версию)

Все данные хранятся на самом устройстве, интернет не нужен.

## Как получить .exe и .apk (без установки программ на ваш компьютер)

Сборку делает бесплатный сервер GitHub.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите **+ → New repository**, назовите `restoranpro`, нажмите **Create repository**.
3. Нажмите **uploading an existing file** и перетащите в окно **всё содержимое** этой папки,
   включая скрытую папку `.github` (если её не видно, включите «показывать скрытые файлы»).
   Нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Сборка запустится сама, занимает 5–10 минут.
   (Если не запустилась: Actions → Build RestoranPRO → Run workflow.)
5. Когда появится зелёная галочка, откройте её и внизу в разделе **Artifacts** скачайте:
   - `RestoranPRO-Windows` — внутри установщик `.exe`
   - `RestoranPRO-Android` — внутри `app-debug.apk`

## Установка
- **Windows / моноблок:** запустите `.exe`, ярлык появится на рабочем столе.
  `F11` — полный экран.
- **Android:** скопируйте `.apk` на телефон, откройте его и разрешите установку из неизвестных источников.

## Если хотите собрать у себя на компьютере
Установите Node.js 20 (https://nodejs.org), затем в папке проекта:

    npm install
    npm run build:win        # установщик попадёт в папку dist/

Для запуска без установки: `npm start`.

## Важно
- Каждое устройство хранит заказы у себя. Синхронизации между телефоном, ПК и моноблоком пока нет.
- Печать чеков (`window.print`) работает на Windows. На Android системная печать из приложения
  не подключена: для чековых принтеров нужен отдельный плагин.
- Файл `app-debug.apk` подходит для установки у себя. Для Google Play нужна подписанная сборка.
